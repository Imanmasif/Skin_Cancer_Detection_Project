# Project Background

## Academic Context

Skin Cancer Detection Using Deep Learning was developed as an undergraduate Final Year Project for the Bachelor of Science in Computer Science programme at Bahria University, Karachi Campus, and was completed in 2022.

The project was developed as a team project. This repository presents the original project implementation and supporting documentation as a portfolio and research record.

## Repository Update

The original project work and experiments were completed in 2022. The repository documentation was later improved to make the existing work easier to understand and review. These documentation changes do not represent new experiments or a claim that the project was newly developed at the time of the repository update.

## Scope

The project investigated binary classification of skin lesions, with the objective of distinguishing melanoma from benign or non-melanoma cases using deep learning and transfer learning.

The original work included:

- comparative experiments using MobileNetV2, VGG16, and InceptionV3;
- a fine-tuned MobileNetV2 experiment;
- image preprocessing and augmentation;
- model training and evaluation; and
- a prototype Android application integrating a TensorFlow Lite model.

## Provenance

The technical descriptions in this repository are based on the original FYP report and the notebooks preserved in the repository. Where the report contains inconsistent numerical details, the documentation avoids presenting an unverified value as definitive.
