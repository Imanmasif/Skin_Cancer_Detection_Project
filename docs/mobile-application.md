# Mobile application component

The original Final Year Project included a prototype Android application intended to demonstrate how the trained classification model could be integrated into a mobile workflow.

According to the project report, the application work involved:

- Android Studio
- TensorFlow Lite for model integration
- Firebase Cloud Storage
- Android Jetpack Navigation components
- ViewModel-based application components

The report describes activities including image selection, model-based classification and presentation of the output within the application.

## Source availability

The current GitHub repository does not contain the complete Android application source. This page documents that the application was part of the original project but does not imply that the mobile app can be rebuilt from the files currently published here.

## Why this is documented

The purpose of this documentation is to provide context for the full scope of the original project. The main reproducible implementation material currently available in the repository is the set of deep-learning notebooks.
