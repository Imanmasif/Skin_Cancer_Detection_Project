# Responsible use

This repository is an academic project record for skin lesion classification using deep learning. It is not a medical device and must not be used as a substitute for clinical examination, diagnosis or treatment.

The historical results in this project were produced in the context of the original undergraduate Final Year Project. Performance on a research dataset does not establish clinical safety, generalisability or suitability for real-world deployment.

Any future use of this work should consider data quality, bias, external validation, privacy, security, regulatory requirements and appropriate clinical oversight.
